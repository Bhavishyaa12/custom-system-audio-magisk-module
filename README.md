# custom-system-audio-magisk-module

A custom system ui audio module to tweak your rooted android phone 

This module seamlessly modifies your /system/media/audio/ui to provide a custom ui sound to your android

Note - The ui sounds are all made by the developer and you can also change the custom sound by extracting the zip file and embeding your own .ogg file in the /system/media/audio/ui/ directory

There is a safety feature which aborts the installation if the script does not get the audio file which helps prevent bootloop in unsupported envieroments
